# 工作区任务看板与小时排期

在一张看板上安排 DeepSeek Harness、Codex 和人工任务。网页、Codex 对话和 Harness 对话共用一份本地 SQLite 数据库。在某一端把测试从 15 点挪到 16 点，另一端重新查询即可看到同一张任务卡的新安排。

## 打开看板

需要 Python 3.9 或以上，所有运行依赖均来自标准库。在仓库根目录启动服务，然后在浏览器打开 [本机看板](http://127.0.0.1:8765/)。

```sh
python3 server.py
```

1. 选择或输入工作区名称，按回车切换。点击“新建任务”，填写标题、执行者、开始时间和预计分钟数。开始时间可以留空。
2. 在看板里查看五种状态，切到时间轴查看一天的排期。拖动时间条可改开始时间，拖动右侧边缘可调时长。也可以打开任务直接填写时间。
3. 实际开工时登记开始，结束时登记完成或失败并填写结果。任务卡保留每次登记的历史。改排期和挑选执行方不会启动模型。

## 从两个 AI 工作台操作

按[双平台接入说明](adapters/README.md)注册本地 MCP 服务。两端可以建任务、调整排期、查询状态、取得看板链接和记录执行。可视面板运行在本机浏览器。用户日常仍在原有的 Codex 或 Harness 会话中发出指令。

首版支持同一台电脑、同一份数据库。默认数据库为 `~/.agent-workspace-timeline/tasks.sqlite3`。自定义时，给网页和宿主 MCP 进程设置相同的 `TIMELINE_DB` 绝对路径。网页默认监听本机 8765 端口；需要调整时统一设置 `TIMELINE_PORT`。退出网页服务后，已配置的 MCP 进程仍可读写排期。

## 验证

```sh
python3 -m unittest discover -s tests -v
```

测试使用临时数据库，覆盖持久化、并发写冲突、状态转换和重试历史、HTTP 接口、MCP 协商与跨进程读写。浏览器人工操作可用独立工作区或临时数据库复现。

首版验收使用真实 Chrome 验证了新建任务、拖动一小时、时长从 60 调到 90 分钟、跨午夜显示、工作区隔离和 375 像素宽屏幕。两个宿主还在隔离配置下完成了同一任务往返读写，详情见[接入与验收记录](adapters/README.md)。
